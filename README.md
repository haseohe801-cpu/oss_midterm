# 캠퍼스 기자재 대여 관리 서비스 - Frontend Midterm Starter

## 시작하기
- VS Code로 폴더를 엽니다.
  `index.html`을 브라우저 또는 VS Code Live Server로 실행합니다.
- 외부 Bootstrap 5.3 CSS CDN은 HTML에 이미 포함되어 있습니다.
- 초기 데이터 3건과 반납 전환/삭제 기능이 제공됩니다.
- 기존 코드는 지우지 말고 TODO Q2~Q5를 중심으로 작성하세요.

## 파일과 역할
- `index.html`: HTML 구조 및 Form, 필터 UI
- `style.css`: CSS
- `app.js`: Array/DOM/Event
- `ANSWERS.md`: 서술형 답안

## Git 제출
- 교수자 Starter 저장소를 clone한 후 개인 Organization repository를 별도 remote로 추가합니다.
- 최소 3회 이상 유효한 commit을 남기고 개인 repository로 push합니다.
